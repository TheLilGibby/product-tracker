Test Auto-Cart Functionality

This page allows you to test the auto-cart functionality using a simulated product. The test scraper simulates various scenarios based on URL parameters.

Test Parameters

Add these parameters to the URL to test different scenarios:

  • success=true|false - Force success or failure (default: 80% success rate)
  • stock=true|false - Set product availability (default: true)
  • price=X - Set product price (default: random between $50-$500)
  • timeout=true - Simulate a timeout
  • name=ProductName - Customize the product name
